# Inter font

`inter-latin-wght-400-800.woff2` is the unmodified Inter Latin variable font
served by Google Fonts. Its local CSS declaration supports normal weights
400–800 and uses `font-display: swap`. The file is the same font URL returned
by the site's previous Google Fonts stylesheet for weights 400, 600, 700,
and 800; self-hosting changes delivery, not the typeface.

The Latin subset includes the English text and curly punctuation used by the
site. The footer heart continues to use the system emoji fallback. Add the
appropriate subsets if the site introduces other writing systems.
